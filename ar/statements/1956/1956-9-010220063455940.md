# ادارة انحصار التبغ

##### المحتوى

تنفيذا لاحكام المادة السابعة عشرة من قانون انحصار التبغ رقم 54 / لسنة 1952 وعملا بالصلاحيات المخولة لنا بموجب قرار مجلس هذه الادارة المرقم ( 2 ) المتخذ في جلسته السادسة عشرة المنعقدة بتاريخ 18/ 10 / 1956 قررنا ان تكون مراكز فحص التبوغ لحاصل / 1956 في الاماكن المبينة ادناه : -

1 – مركز السليمانية ويجري فيه فحص بتوغ السليمانية وجوارتا واغجد وبنجوين 0

2 – مركز بشددر ( قلعة دزه ) ويجري فحص تبوغ قضاء بشدر 0

3 – مركز حلبجه ويجري فيه فحص تبوغ قضاء حلبجة 0

4 – مركز راوندوز ويجري فيه فحص تبوغ قضاء راوندوز وقضاء الزيبار 0

5– مركز كويسنجق ويجري فيه فحص تبوغ قضاء كويسنجق 0

6 – مركز رانية ويجري فيه فحص تبوغ قضاء رانية 0

7 – مركز شقلاوة ويجري فيه فحص تبوغ قضاء شقلاوة 0

8 – مركز الموصل ويجري فيه فحص تبوغ قضاء عقره 0

9 – مركز دهوك ويجري فيه فحص تبوغ قضاء ( دهوك وزاخو وعمادية ) 0
