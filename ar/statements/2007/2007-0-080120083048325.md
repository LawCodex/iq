# تعديل المادة 23 من قانون مؤسسة الشهداء رقم 3 لسنة 2006

##### استناد

استنادا للصلاحيات المخولة لنا بموجب المادة ( 8 ) من قانون النشر بالجريدة الرسمية رقم ( 78 ) لسنة 1977 اصدرنا البيان الاتي :
اولا-يضاف ما يلي الى الفقرة ( خامسا ) من المادة ( 23 ) من قانون مؤسسة الشهداء رقم ( 3 ) لسنة 2006 ( ويشترط ان يكون من ذوي الشهداء حصرا ) .
ثانيا-ينشر هذا البيان في الجريدة الرسمية .
نصير عايف العاني
رئيس ديوان رئاسة الجمهورية
25 / 7 / 2007
